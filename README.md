# Battle EXP Bar

A [Gen1Recomp](https://github.com/bryanthaboi/gen1recomp) mod that shows a Gen 3+ style experience bar under the player's HP bar in battle.

## Features

- Fills right-to-left toward the next level
- Animates on EXP gain and level-up
- Classic and wide battle layouts
- Style options: **Blue** (default), **Black**, or **Off**

## Install

1. Download `battle_exp_bar-1.0.1.zip` from [Releases](../../releases)
2. In Gen1Recomp: **F10** → **Import mod .zip**
3. Enable **Battle EXP Bar** and restart if needed

Or copy this folder to:

```text
~/Library/Application Support/pokemon-love2d/mods/battle_exp_bar/
```

## Options

F10 → Battle EXP Bar → **EXP BAR STYLE**

| Choice | Effect |
| --- | --- |
| BLUE | Later-gen blue fill (default) |
| BLACK | Black fill |
| OFF | Hide the bar |

## Notes

- Presentational only (`affects_link: false`)
- Don't stack with Quality of Life's **BATTLE EXP BAR** — pick one
- Requires Gen1Recomp with mod API 2
